# Lictor repository rules

Read PROJECT_DESC.md (owner-controlled; never edit), PROJECT_SPEC.md, wiki/WIKI.md,
wiki/index.md, wiki/agent-rules.md and wiki/repos/lictor.md before changes.
Lictor-specific knowledge belongs only in this co-versioned wiki, never a parent
or sibling fallback. Every commit appends a ledger row and log entry here.
Use Gograph sessions, plans and reviews for Go changes. Run make verify before
every commit, and make wiki-check for wiki edits. Report every red honestly.
Git mutations need explicit owner authorization; stage exact files only. No
secrets, consumer changes, tags, release publication or tap edits without scope.
Keep fixed-argv execution bounded. Preserve ported verdicts and evidence text;
never duplicate a generic judgement to bypass a tool limitation. Clock inputs
belong to the request; no real-clock tests. Follow the parent workspace rules.
